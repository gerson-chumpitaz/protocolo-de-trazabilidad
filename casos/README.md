# Casos documentados

Esta carpeta describe dos usos reales del Protocolo de Trazabilidad por parte de su autor, en trabajos académicos. Cada caso documenta la mecánica del método: qué capas de documentos se produjeron, cómo se ancló y etiquetó cada afirmación, qué se verificó y qué no. No contiene los entregables ni las fuentes.

## Cómo leerlos

Los casos se reconstruyeron a partir de los documentos de trabajo del propio autor (fichas, informes de verificación, el registro de una sesión de trabajo con un asistente de IA). No son auditorías independientes. Lo que aquí se afirma sobre el proceso es lo que esos documentos registran; cuando no registran algo, el caso lo dice en lugar de suponerlo.

Siguen las reglas de [`ANONIMIZACION.md`](../ANONIMIZACION.md). Por eso no nombran el curso, las personas, la institución, las fuentes ni la empresa analizada, no reproducen preguntas ni respuestas de ninguna evaluación y no citan páginas de los libros usados. Los ejemplos de formato usan datos inventados.

## Diferencias entre la práctica y el kit

El kit de este repositorio es una versión más estricta que la práctica documentada en estos casos. En la práctica, las fichas anclan por bloque y rango de páginas y no llevan cita literal; la comprobación automática de frases se aplicó a los productos derivados. El kit pide una cita literal por afirmación en la ficha para que el verificador pueda comprobarla. Cada caso señala dónde está esa diferencia.
