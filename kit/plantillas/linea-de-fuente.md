# Línea de fuente

Formato de la fuente de dos saltos que acompaña a cada ítem de un producto derivado (una evaluación, un caso, un análisis). El primer salto lleva al documento original, con página. El segundo lleva a la ficha de síntesis, con sección. Cualquier ítem se puede rastrear hasta su página en dos pasos.

## Formato

```
[Fuente: <autor> (<año>), <capítulo>, sección "<título>", p. <número>; síntesis: <ficha>, sección <número>]
```

## Ejemplo con datos inventados

```
[Fuente: Apellido (2020), Capítulo 4, sección "La segmentación del mercado", p. 112; síntesis: Ficha_Cap04, sección 2]
```

## Variantes

Cuando la afirmación abarca más de una página:

```
[Fuente: Apellido (2020), Capítulo 4, sección "La segmentación del mercado", pp. 112-114; síntesis: Ficha_Cap04, sección 2]
```

Cuando el ítem se apoya en dos secciones de la misma ficha:

```
[Fuente: Apellido (2020), Capítulo 4, sección "La segmentación del mercado", p. 112; síntesis: Ficha_Cap04, secciones 2 y 3]
```

Cuando el ítem usa un caso además del libro, se escriben dos líneas, una por documento, cada una con sus dos saltos.

Cuando la fuente no tiene marcadores de página, se sustituye la página por la sección o el bloque, y se declara en el cierre que no hubo anclaje a página:

```
[Fuente: Apellido (2020), Capítulo 4, sección "La segmentación del mercado", sin paginación; síntesis: Ficha_Cap04, sección 2]
```

Cuando la fuente no tiene títulos de sección, se escribe "sin secciones" en lugar del título:

```
[Fuente: Cervantes (2021), Capítulo primero, sin secciones, p. 1; síntesis: ficha_cap1, sección 1]
```

## Reglas

1. Toda línea lleva los dos saltos. Una línea con solo uno de ellos está incompleta.
2. El título de la sección se copia tal como aparece en la fuente.
3. Si el ítem no puede rastrearse hasta una página en estos dos pasos, no se incluye en el producto y se reporta en el informe de verificación.
4. Si el ítem pertenece al eje de origen "inferencia" o "recomendación", no lleva línea de fuente de hecho. Se escribe en su lugar la línea de las afirmaciones que lo sostienen, precedida de la palabra "Sustentado en:".

```
Sustentado en: [Fuente: ...]; [Fuente: ...]
```
